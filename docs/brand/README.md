# kanri brand assets

All files are pure vector: filled paths only, no strokes, no fonts, no CSS (except favicon.svg). They scale cleanly in Figma, Illustrator, and the browser.

- **Figma:** drag the file in, or paste the SVG code. Scale it with K (the scale tool), or constrain it to "Scale". Nothing in the files depends on a stroke width.
- The wordmark is outlined from Outfit SemiBold, tracked −0.045em. No font install needed.

| File | Use |
|---|---|
| kanri-mark.svg | Mark on dark backgrounds (default) |
| kanri-mark-light-bg.svg | Mark on light backgrounds |
| kanri-mark-black.svg / -white.svg | One colour: print, embossing, overlays |
| kanri-mark-small.svg | Heavier small cut, for 24px and below |
| favicon.svg | Small cut; switches ink colour with the OS light/dark mode |
| kanri-app-icon.svg | 1024 × 1024 app / PWA icon |
| kanri-wordmark-white.svg / -ink.svg | Wordmark only |
| kanri-lockup-horizontal(-light-bg).svg | Mark + wordmark, side by side |
| kanri-lockup-stacked(-light-bg).svg | Mark over wordmark |

Colours: lime #aff33e · white #f8fafc · ink #0f172a · backdrop #020617
Clear space: one dot diameter on every side. Minimum size: 16px for the small cut, 24px for the regular mark.

In the app: `<link rel="icon" type="image/svg+xml" href="/favicon.svg">`
